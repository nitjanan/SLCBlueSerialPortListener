# แบบหัวกระดาษบิล (ReportMain)
# วางไฟล์นี้ชื่อ config_billheader.txt ไว้ในโฟลเดอร์ข้อมูลของโปรแกรม
# หรือจะเลือกแบบจากหน้าจอ ucSetting แท็บ Setting ก็ได้ (โปรแกรมจะเขียนบรรทัด Header= ให้เอง)
#
# ปกติ ชื่อบริษัท / ที่อยู่ / เบอร์โทร ที่พิมพ์บนบิล ดึงมาจากตาราง Company ในฐานข้อมูล
# ถ้าต้องพิมพ์ในนามสาขาหรือนิติบุคคลอื่นโดยไม่แตะฐานข้อมูล ให้ตั้งชุดไว้ที่นี่แล้วเลือกใช้
#
# Header = หมายเลขชุดที่ใช้อยู่
#          0 หรือไม่ระบุ = ใช้ค่าจากฐานข้อมูลตามเดิม (ค่าเริ่มต้น)
#          ถ้าชี้ไปยังชุดที่ไม่มีอยู่จริง จะถอยไปใช้ค่าจากฐานข้อมูลเช่นกัน
#
# แต่ละชุดใช้คีย์ HeaderN.* โดย N เริ่มจาก 1 ไล่ขึ้นไป
#   HeaderN.Name        ชื่อที่แสดงให้เลือกในหน้าจอ (ไม่ได้พิมพ์ลงบิล)
#   HeaderN.CompanyName -> PCompanyName
#   HeaderN.Address     -> PAddress
#   HeaderN.Telephone   -> PTelephone
#
# ฟิลด์ที่เว้นว่างไว้ = ไม่แทนที่ ให้ใช้ค่าจากฐานข้อมูลเฉพาะฟิลด์นั้น
# จึงตั้งเฉพาะชื่อบริษัทอย่างเดียว แล้วปล่อยที่อยู่กับเบอร์โทรตามฐานข้อมูลได้

Header=0

Header1.Name=สาขาหลัก
Header1.CompanyName=บริษัท ตัวอย่าง จำกัด
Header1.Address=123 ถ.ตัวอย่าง ต.ตัวอย่าง อ.เมือง จ.ตัวอย่าง 80000
Header1.Telephone=077-000-000

Header2.Name=สาขาสุราษฎร์ธานี
Header2.CompanyName=บริษัท ตัวอย่าง จำกัด (สาขาสุราษฎร์ธานี)
Header2.Address=456 ถ.ตัวอย่าง ต.มะขามเตี้ย อ.เมือง จ.สุราษฎร์ธานี 84000
Header2.Telephone=077-111-111

# ตัวอย่างชุดที่เปลี่ยนเฉพาะชื่อบริษัท ที่อยู่กับเบอร์โทรยังใช้ของฐานข้อมูล
Header3.Name=เปลี่ยนเฉพาะชื่อบริษัท
Header3.CompanyName=บริษัท ตัวอย่าง (2) จำกัด
